# 04. 다음 단계 로드맵 — 1호 고객 이후 무엇을, 어떤 순서로

> 큰 원칙: **고객이 생기기 전에 많이 만들지 마라.**
> 멋진 기능보다, 돈 내는 고객 1명이 100배 가치 있습니다. 매 단계는 "다음 고객을 위해 꼭 필요한가?"로 판단하세요.

---

## Phase 1 — 1호 고객 안정화 (가장 중요)

목표: **첫 가게에서 봇이 진짜로, 안 깨지고, 사장이 만족할 만큼 잘 돈다.**

할 일:
- 매일 손님↔봇 대화 로그를 직접 확인. 이상한 답·틀린 답을 바로 수정.
- 봇이 모르는 질문 목록을 모아 FAQ를 보강(이게 곧 제품의 핵심 자산).
- **API 실제 비용을 측정.** 메시지당 진짜 얼마 드는지 숫자로 확보 → 03 파일의 가격을 현실화.
- 사장에게 "어떤 게 제일 도움됐어요?" 물어 **한 줄 후기**와 **개선점** 확보.
- 작동 화면 스크린샷·후기를 영업 자료로 저장(허락받고).

이 단계 완료 기준:
- [ ] 일주일 동안 사장이 직접 손 안 대도 봇이 잘 돌아간다.
- [ ] 큰 오답·장애가 없다.
- [ ] 사장이 "이거 좋네요"라고 말한다. (후기 1개 확보)
- [ ] 메시지당 실제 비용을 안다.

경고:
- 여기서 대시보드·결제 자동화 같은 거 만들지 마세요. **아직 이릅니다.**
- 1호가 흔들리는데 2호 영업 가지 마세요. 첫 고객이 불만이면 입소문이 거꾸로 돕니다.

---

## Phase 2 — 2~5호 확장 (반복 가능한지 증명)

목표: **"한 번 운 좋게"가 아니라 같은 걸 반복할 수 있다**를 증명.

할 일:
- 1호의 후기·스크린샷을 들고 같은 업종 **5곳 더** 영업(02 파일 멘트 사용).
- 2호부터는 **정가**(무료 금지). 무료는 1호로 끝.
- 설치 과정을 **체크리스트 문서**로 만든다(가게 정보 받기 → 봇 셋업 → 테스트 → 인수인계). 매번 머리 안 쓰게.
- 업종 공통 FAQ 템플릿을 만들어 두면 신규 설치가 **반나절**로 줄어듭니다.
- 결제는 아직 수동(계좌이체·정기 송금)이어도 됩니다. 5곳은 손으로 관리 가능.

완료 기준:
- [ ] 돈 내는 고객 3~5곳.
- [ ] 신규 설치가 처음보다 눈에 띄게 빨라짐.
- [ ] 월 순익이 "이거 계속할 만하다" 싶은 수준.

경고:
- 5곳도 안 됐는데 "SaaS 플랫폼" 만들지 마세요. 수동으로 버틸 수 있는 규모입니다.
- 업종을 너무 일찍 늘리지 마세요. 한 업종에서 5곳 먼저.

---

## Phase 3 — 자동화 / SaaS화 (손이 모자랄 때)

목표: **혼자서 더 많은 가게를 관리**할 수 있게, 반복 작업을 시스템으로.

> 시작 신호: 가게가 **10곳 안팎**이 되어 수동 관리가 버거워질 때. 그 전엔 하지 마세요.

할 일(우선순위 순):
1. **셀프 온보딩 폼**: 사장이 가게 정보를 직접 입력하면 봇이 자동 셋업 → 당신의 설치 시간 절감.
2. **정기결제 자동화**: 구독 결제·영수증 자동화로 매달 돈 받는 수고 제거.
3. **다중 가게 관리 화면**: 가게별 상태·문의량·오류를 한눈에.
4. **비용/사용량 모니터링**: 가게별 API 사용량·한도 초과 알림(마진 보호와 직결).

완료 기준:
- [ ] 신규 가게 설치에 당신 손이 거의 안 들어간다.
- [ ] 결제가 자동으로 돌아간다.
- [ ] 가게가 늘어도 운영 시간이 비례해서 늘지 않는다.

경고:
- 자동화는 "이미 있는 수동 절차"를 옮기는 것입니다. **수동으로 먼저 검증된 흐름만** 자동화하세요. 안 그러면 안 쓸 기능을 만들게 됩니다.

---

## Phase 4 — 기능 추가 (고객이 진짜 원할 때만)

목표: **이탈 막고 단가 올리기.** 단, 고객 요청·이탈 신호에 근거해서만 추가.

후보 기능(요청 많은 순으로):
- **웹/외부 예약 연동**: 네이버 예약·캘린더 등과 연결해 봇이 빈 시간 안내·예약 접수까지. (예약형 업종에 큼)
- **긴 답변 콜백**: 복잡한 문의는 봇이 "사장님께 전달했어요" 후, 사장이 답을 넣으면 손님에게 자동 회신.
- **통계 대시보드**: 월 문의 수·자주 묻는 질문 Top·놓칠 뻔한 문의 → 사장에게 "이만큼 일 덜었어요"를 숫자로 보여줌(해지 방어 + 상위 티어 설득).
- **알림/리마인더**: 예약 전날 안내, 노쇼 줄이기.

가격 연결:
- 이런 고급 기능은 **상위 티어(프리미엄)**로 묶어 월 구독료를 올릴 근거로 쓰세요.

경고:
- 한 고객이 부탁했다고 다 만들지 마세요. **3곳 이상이 같은 걸 원할 때** 만드는 게 안전합니다.
- 기능을 늘릴수록 유지보수·API 비용도 늘어납니다. 마진 계산(03 파일)을 다시 돌려보세요.

---

## 전체 한 장 요약

| Phase | 신호 | 핵심 목표 | 절대 하지 말 것 |
|---|---|---|---|
| 1. 1호 안정화 | 첫 유료 고객 | 안 깨지게, 만족, 실비용 측정 | 대시보드·자동화 만들기 |
| 2. 2~5호 확장 | 1호 안정됨 | 반복 가능 증명, 정가 판매 | 무료 남발, SaaS 플랫폼 |
| 3. 자동화/SaaS화 | 가게 ~10곳, 손 부족 | 혼자 더 많이 관리 | 미검증 흐름 자동화 |
| 4. 기능 추가 | 고객 반복 요청 | 이탈 방어·단가 인상 | 한 명 요청에 다 만들기 |

> 마지막으로: 압도당할 땐 **"지금 다음 고객 1명에게 필요한 가장 작은 일"** 하나만 하세요. 그거 하나면 충분합니다. 로드맵은 한 번에 다 하는 게 아니라, 한 칸씩 밟는 계단입니다.
