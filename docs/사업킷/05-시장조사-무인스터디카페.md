# 📊 시장조사 결과 — 왜 "무인 스터디카페"인가 (2026)

> 웹 시장조사 후 1순위 타깃으로 선정. 이 문서는 근거 + 영업 전략입니다.

## 한 줄 결론
**무인매장은 폭발 성장 중인데, "사람이 없어서 손님 문의를 못 받는" 게 가장 큰 약점이다.
그 약점을 정확히 메우는 게 우리 카톡 AI 상담봇이다. 그중 스터디카페가 최적.**

## 근거 데이터
- **무인매장 전국 5만 개 돌파.** 예비창업자 **32.6%**가 2026년 최고 유망업종으로 "무인"을 선택.
- 무인 업종 비중: 아이스크림 22%, 세탁소 22%, **스터디카페 11%**, 사진관 8%, 코인노래방 7%.
- 무인매장의 새 리스크 = **고장·유지보수·문의 응대**. 사람이 없으니 손님이 물어볼 곳이 없음 → 봇 수요의 본질.
- 소상공인 **66.9%**가 이미 고객응대에 AI 챗봇/통화비서 활용. 단, 활용 수준은 "걸음마" → **솔루션 빈틈**.
- **카카오가 2026년까지 2만 개 사업장에 카카오톡 채널 보급 지원** → 봇 얹을 인프라가 이미 깔림.
- 카카오 발표: 카톡 AI 챗봇이 소상공인 응대비용 **1414억원 절감**.

## 왜 스터디카페가 1순위냐
| 기준 | 평가 |
|------|------|
| 문의량 (봇 필요성) | ⭐⭐⭐⭐ 이용방법·요금·연장·환불·고장 문의 끊임없음 |
| 지불 여력 | ⭐⭐⭐⭐ 월 정기권 매출 안정적, 사장님 여유 있음 |
| 다점포 가능성 | ⭐⭐⭐⭐⭐ 한 사장이 2~5개 운영 多 → 한 명 잡으면 여러 개 |
| 문의 정형화 | ⭐⭐⭐⭐⭐ 질문 패턴이 정해져 있어 봇이 잘 맞음 |
| 사람 공백 | ⭐⭐⭐⭐⭐ 24시간 무인 → 야간 문의 100% 봇 몫 |

## 영업 한 줄 멘트 (무인 스터디카페 전용)
> "사장님, 무인이라 야간에 손님이 '도어락 안 열려요', '환불돼요?' 물어볼 데가 없잖아요.
> 그거 카톡으로 AI가 24시간 자동 응대해드려요. 사장님 전화 안 울리게요."

## 첫 고객 잡는 법
1. 네이버지도/카카오맵에서 **"무인 스터디카페"** 검색 → 동네 매장 리스트업
2. 각 매장 **카카오톡 채널**이 이미 있는지 확인 (대부분 있음 → 얹기만 하면 됨)
3. 사장님께 **이 데모 봇**(`examples/무인스터디카페.json`)을 직접 보여주기:
   "이거 사장님 매장 정보로 바꾸면 바로 이렇게 답해요" (시연)
4. **"1호점 한 달 무료로 깔아드릴게요. 좋으면 매장당 월 OO원"** 제안
5. 다점포 사장이면 → 전 지점 묶음 할인 제안
