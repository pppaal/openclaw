# 2단계: 카카오톡에 연결하기 💬

1단계(`01-내컴퓨터에서-실행하기.md`)에서 챗봇이 내 컴퓨터에서 잘 답하는 걸 확인했나요?
이제 그 챗봇을 **카카오톡 손님**과 연결할 차례예요.

> ⚠️ **먼저 솔직하게 알려드릴 것**
> - 카카오는 **개인 1:1 카톡(친구와 주고받는 채팅)** 을 봇으로 자동 답변하게 **허용하지 않아요**. 그건 불가능합니다.
> - 대신 **비즈니스용 "카카오 채널"** 을 만들고, 거기에 **챗봇**을 붙이는 방식은 가능해요. 우리가 할 게 바로 이거예요.
> - 손님은 우리 가게의 **카카오 채널**에 말을 걸고, 우리 챗봇이 답하는 구조입니다.

---

## 전체 그림 (한눈에)

```
손님 (카카오톡)
   ↓ 말을 검
우리 가게 카카오 채널 (비즈니스)
   ↓
카카오 i 오픈빌더 챗봇  ← 카카오가 주는 챗봇 만드는 도구
   ↓ "스킬 URL"로 질문 전달
우리 서버 (/kakao/skill)  ← 1단계에서 만든 우리 프로그램
   ↓
Claude(AI)  → 답을 만들어 손님에게 전달
```

쉽게 말하면:
- **카카오 채널 + 오픈빌더 챗봇** = 손님과 만나는 **가게 문(門)**
- **우리 서버(/kakao/skill)** = 그 문 뒤에서 실제로 답을 만드는 **우리 직원**
- 두 개를 연결하는 **전화선**이 바로 **"스킬 URL"** 이에요.

---

## 준비물

- 1단계를 끝낸 상태 (`.env`, `business.json` 준비 완료, `npm run chat` 이 잘 됨)
- **ngrok** (엔그록) — 내 컴퓨터를 잠깐 인터넷에 공개해 주는 도구. 뒤에서 설치합니다.
- **카카오 채널** — 가게용 카카오 채널. (카카오 채널 관리자센터 `business.kakao.com` 에서 미리 하나 만들어 두면 좋아요. 무료입니다.)

---

## 1. 우리 서버 켜기

터미널(검은 창)을 1단계처럼 챗봇 폴더에서 열고, 아래를 입력하고 Enter:

```
npm run kakao
```

- 이건 손님 질문을 받을 **우리 서버를 켜는** 명령이에요.

> ✅ **성공 신호**: 아래 비슷한 글자가 나오고 창이 그대로 켜져 있어요.
> ```
> 🦞 카카오 웹훅 서버 실행 중: http://localhost:3000/kakao/skill
> ```
> `localhost:3000` 은 "내 컴퓨터의 3000번 창구"라는 뜻이에요.
>
> ❌ **막히면**: 키 오류가 나면 1단계의 `.env` 설정을 다시 확인하세요. 포트(3000)가 이미 쓰인다는 오류면, 다른 프로그램을 끄거나 컴퓨터를 재시작해 보세요.

> 📌 이 터미널 창은 **계속 켜 둬야** 해요. 닫으면 서버가 꺼집니다.

---

## 2. ngrok으로 내 컴퓨터를 인터넷에 잠깐 공개하기 🌐

### 왜 필요한가요?

지금 우리 서버는 `localhost`(내 컴퓨터 안)에서만 보여요. 하지만 **카카오는 인터넷 어딘가에서** 우리 서버를 불러야 합니다. 그래서 내 컴퓨터에 **인터넷 주소(공개 URL)** 를 잠깐 붙여줘야 해요. 이걸 해주는 도구가 **ngrok**입니다.

> 비유: 우리 가게(내 컴퓨터)에 손님이 찾아올 수 있게 **임시 도로와 주소**를 깔아주는 거예요.

### 설치하고 실행하기

1. 브라우저로 **https://ngrok.com** 에 접속해 무료 가입합니다.
2. 사이트 안내(Setup/Download)에 따라 **윈도우용 ngrok을 내려받아 설치**합니다.
3. 사이트에 나오는 **authtoken(인증 토큰) 연결 명령**을 한 번 실행하라고 안내할 거예요. 그 명령을 복사해 **새 터미널 창**에 붙여넣고 Enter. (이건 처음 한 번만)
4. **새 터미널 창**(서버 켜둔 창 말고 다른 창)에서 아래를 입력하고 Enter:

   ```
   ngrok http 3000
   ```

   - 뜻: "내 컴퓨터 3000번 창구를 인터넷에 공개해 줘." (3000은 1번에서 켠 서버 번호)

> ✅ **성공 신호**: 화면에 `Forwarding` 줄과 함께 이런 **https 주소**가 나와요.
> ```
> Forwarding   https://abcd-1234.ngrok-free.app -> http://localhost:3000
> ```
> 여기서 `https://abcd-1234.ngrok-free.app` 이 **우리의 공개 주소**예요. (사람마다 다릅니다.) 이 주소를 복사해 두세요.
>
> ❌ **막히면**: `ngrok`을 모른다는 오류가 나면 설치가 덜 된 거예요. 4번에서 안내한 설치/토큰 단계를 다시 하세요.

> 📌 이 ngrok 창도 **계속 켜 둬야** 해요. 그리고 **무료 ngrok은 껐다 켜면 주소가 바뀝니다.** 주소가 바뀌면 아래 3-3에서 URL을 다시 넣어줘야 해요.

이제 우리의 **스킬 URL**은 이렇게 됩니다(끝에 `/kakao/skill` 을 꼭 붙여요):

```
https://abcd-1234.ngrok-free.app/kakao/skill
```

(`abcd-1234...` 부분은 내 ngrok 주소로 바꾸세요.)

## 3. 카카오 i 오픈빌더에서 챗봇 만들고 연결하기

### 3-1. 오픈빌더 들어가기 & 챗봇 만들기

1. 브라우저로 **https://i.kakao.com** 에 접속해 카카오 계정으로 로그인합니다.
2. **봇 만들기**(새 챗봇 만들기)를 눌러 챗봇을 하나 만듭니다.
   - 봇 종류를 고르라고 하면 **카카오톡 채널** 용 챗봇으로 만들고, 앞서 준비한 **우리 가게 카카오 채널**을 연결합니다.

> ✅ **성공 신호**: 새 챗봇의 관리 화면(왼쪽에 시나리오, 스킬 같은 메뉴가 있는 화면)이 보여요.

### 3-2. 스킬 등록하기 (우리 서버 주소 넣기)

1. 왼쪽 메뉴에서 **스킬** 을 클릭합니다.
2. **스킬 만들기**(또는 +)를 누릅니다.
3. **스킬 URL** 칸에 2번에서 만든 우리 주소를 붙여넣습니다:

   ```
   https://abcd-1234.ngrok-free.app/kakao/skill
   ```

   - ⚠️ 끝에 **`/kakao/skill`** 이 꼭 붙어 있어야 해요.
   - ⚠️ `http` 가 아니라 **`https`** 여야 해요(ngrok이 준 https 주소 그대로).
4. 저장합니다.

> ✅ **성공 신호**: 스킬 목록에 방금 만든 스킬이 보이고, URL이 우리 주소로 저장돼 있어요.

### 3-3. 폴백 블록에 스킬 연결하기

"폴백 블록"은 **정해진 답이 없는 모든 질문이 흘러 들어오는 곳**이에요. 손님은 무슨 말이든 하니까, 여기에 우리 AI를 연결하면 **어떤 질문이든 AI가 답**하게 됩니다.

1. 왼쪽 메뉴에서 **시나리오** → **폴백 블록**(Fallback)을 엽니다.
2. 그 블록의 응답 설정에서 **스킬 사용**(또는 스킬 데이터 사용)을 켜고, 방금 만든 **우리 스킬**을 선택합니다.
3. 봇이 손님에게 보낼 답으로 **스킬에서 받은 텍스트**가 나가도록 설정하고 저장합니다.
   - (오픈빌더 화면 구성은 가끔 바뀌어요. "이 블록에서 스킬을 호출하고, 그 결과를 말풍선으로 답한다"는 흐름만 맞으면 됩니다.)

> ✅ **성공 신호**: 폴백 블록에 우리 스킬이 연결된 상태로 저장됐어요.

### 3-4. 봇 테스트로 확인하기

1. 화면 위쪽/오른쪽의 **봇 테스트**(말풍선 모양 테스트 창)를 엽니다.
2. 손님처럼 질문을 적어 보냅니다. 예: `영업시간 알려줘`, `커트 얼마예요?`

> ✅ **성공 신호**: 우리 `business.json` 내용대로 AI가 답해요. 🎉
> 이때 **서버 터미널 창**과 **ngrok 창**에도 요청이 들어온 기록이 올라옵니다.
>
> ❌ **막히면**:
> - `npm run kakao` 서버 창이 켜져 있나요?
> - ngrok 창이 켜져 있고, 스킬 URL이 **현재** ngrok 주소와 같나요? (ngrok을 재시작했다면 주소가 바뀌었을 수 있어요 → 3-2에서 새 주소로 수정)
> - 스킬 URL 끝에 `/kakao/skill` 이 붙어 있나요?

## 4. 5초 제한에 대한 솔직한 이야기 ⏱️

카카오 오픈빌더는 **답을 약 5초 안에** 받아야 해요. 안 그러면 손님 화면에 오류가 납니다.

- 그래서 우리 프로그램은 카카오로 들어온 질문일 때 **자동으로 빠른 모드**로 답하도록 만들어져 있어요. 사장님이 따로 설정할 건 없습니다.
- 그래도 아주 긴 답이나 복잡한 질문은 5초를 넘길 수 있어요. 이 경우를 위한 **콜백(callback)** 이라는 더 나은 방식이 있는데, 그건 **나중에 추가할 업그레이드**예요. 지금은 일반 손님 문의 정도면 충분히 동작합니다.

---

## 5. ngrok은 "테스트용"입니다 — 실제 운영은 어떻게? 🏪

- ngrok은 **테스트할 때만** 쓰는 임시 도로예요. 내 컴퓨터를 끄거나 ngrok 창을 닫으면 챗봇도 멈춰요. 그리고 무료 주소는 껐다 켜면 바뀝니다.
- 손님이 **언제 와도 24시간 답하게** 하려면, 우리 서버를 **항상 켜져 있는 곳(호스팅/서버)** 에 올려야 해요.
- 나중에 고려할 수 있는 곳(지금 자세히 몰라도 됩니다):
  - **Railway**, **Render** — 코드를 올리면 알아서 켜 주는 간편한 서비스
  - **작은 VPS** — 인터넷에 늘 켜져 있는 작은 임대 컴퓨터
- 실제 서비스로 옮기면 그곳이 주는 **고정 https 주소** 뒤에 `/kakao/skill` 을 붙여 오픈빌더 스킬 URL만 바꿔주면 됩니다. (방식은 지금과 똑같아요.)

> 지금 단계에서는 **ngrok + 봇 테스트로 잘 동작하는지 확인**하는 것까지만 하면 충분합니다. 그게 되면 절반 이상 온 거예요! 👏
