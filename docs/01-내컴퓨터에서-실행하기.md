# 1단계: 내 컴퓨터에서 챗봇 실행하기 🤖

이 문서는 **코드를 한 번도 실행해 본 적 없는 사장님**을 위해 만들었어요.
천천히 한 줄씩만 따라 오시면 됩니다. 어려운 말은 그때그때 쉽게 풀어 설명할게요.

> 비유로 먼저 설명하면요,
> - **Claude API 키** = 우리 가게가 AI에게 "일 시켜도 돼요"라고 보여주는 **출입증**이에요.
> - **business.json** = AI가 손님한테 답할 때 보는 **우리 가게 안내문**이에요. 여기 적힌 내용만 보고 답해요.
> - **터미널** = 컴퓨터에게 글자로 명령을 시키는 **검은 창**이에요. 무섭지 않아요.

준비물: 윈도우 컴퓨터, 그리고 이미 설치된 Node.js. (Node.js는 이 챗봇을 돌리는 **엔진** 같은 거예요.)

---

## 목차

1. 터미널(검은 창) 여는 법
2. Claude API 키 발급받기 (💳 돈이 들어요)
3. 키를 `.env` 파일에 넣기
4. 우리 가게 정보를 `business.json`에 적기
5. 설치하고 실행해서 손님처럼 대화해 보기
6. 😵 막혔을 때 (자주 나는 오류 모음)

---

## 0. 먼저: 터미널(검은 창) 여는 법

터미널은 컴퓨터에게 글자로 명령하는 창이에요. 이 챗봇 폴더 안에서 열어야 합니다.

1. 챗봇 폴더(파일들이 들어 있는 폴더)를 **파일 탐색기**로 엽니다.
   - `package.json`, `business.example.json` 같은 파일이 보이는 그 폴더예요.
2. 폴더 안 빈 공간의 **주소 표시줄**(위쪽에 폴더 경로가 적힌 칸)을 마우스로 한 번 클릭합니다.
3. 거기에 적힌 글자를 모두 지우고 `powershell` 이라고 친 뒤 **Enter**를 누릅니다.
4. 파란색 또는 검은색 창이 뜨면 성공입니다.

> ✅ **성공 신호**: 창이 떴고, 맨 아래 줄 끝에 `>` 같은 기호와 깜빡이는 커서가 보여요. 이제 여기에 명령을 적을 거예요.
>
> ❌ **막히면**: 창이 안 뜨면, 윈도우 검색창에 `PowerShell`을 쳐서 열고, 거기서 우리 폴더로 이동해도 됩니다(이건 조금 어려우니 위 방법을 먼저 권해요).

앞으로 "명령을 입력하세요"라고 하면 **이 창에 글자를 적고 Enter를 누르는 것**을 말합니다.

## 1. Claude API 키 발급받기 💳

AI(Claude)는 무료가 아니에요. 손님 질문에 답할 때마다 아주 작은 사용료가 듭니다.

> 💰 **비용 솔직하게**: 가게에서 가볍게 쓰는 정도(하루 손님 문의 몇십 건)면 보통 **월 5~20달러(약 7천~3만원)** 정도예요. 많이 쓰면 더 나올 수 있어요. 카드 등록이 필요합니다.

### 1-1. 회원가입

1. 인터넷 브라우저(크롬 등)를 열고 주소창에 **https://platform.claude.com** 을 칩니다.
2. **Sign up**(회원가입) 버튼을 눌러 이메일로 가입합니다. (이미 계정이 있으면 **Log in**으로 로그인)

> ✅ **성공 신호**: 로그인 후 영어로 된 관리 화면(대시보드)이 보여요.

### 1-2. 카드(결제) 등록

1. 왼쪽 또는 위쪽 메뉴에서 **Billing**(결제) 또는 **Plans & Billing** 항목을 찾아 클릭합니다.
2. 안내에 따라 **신용/체크카드를 등록**하고, 소액(예: $5)을 충전하거나 결제 수단을 연결합니다.

> ✅ **성공 신호**: 결제 화면에 등록한 카드 또는 잔액($5 등)이 보여요.
>
> ❌ **막히면**: 카드를 등록하지 않으면, 나중에 챗봇을 돌릴 때 "결제가 안 됐다"는 오류가 납니다. 꼭 먼저 등록하세요.

### 1-3. API 키 만들기

1. 메뉴에서 **API Keys**(또는 **Keys**)를 클릭합니다.
2. **Create Key**(키 만들기) 버튼을 누릅니다.
3. 이름은 아무거나(예: `우리가게봇`) 적고 만듭니다.
4. `sk-ant-...` 로 시작하는 긴 글자가 나옵니다. 이게 **API 키**예요.
5. **Copy**(복사) 버튼을 눌러 복사합니다. 메모장에 잠깐 붙여 두세요.

> ⚠️ **아주 중요**: 이 키는 **비밀번호**와 같아요.
> - 절대 다른 사람에게 보내지 마세요(카톡, 메일, 캡처 포함).
> - 인터넷(깃허브 등)에 올리지 마세요.
> - 이 키가 새어 나가면 모르는 사람이 내 카드로 AI를 쓸 수 있어요.
> - 키 화면을 닫으면 **다시 볼 수 없어요**. 잃어버리면 새로 만들면 됩니다(걱정 마세요).

## 2. 키를 `.env` 파일에 넣기

`.env`(점-env)는 **비밀 설정을 적어두는 파일**이에요. 방금 만든 키를 여기에 넣습니다.

1. 챗봇 폴더 안에 있는 **`.env.example`** 파일을 찾습니다.
2. 그 파일을 **복사**한 뒤(마우스 우클릭 → 복사, 빈 곳에 붙여넣기), 복사본 이름을 **`.env`** 로 바꿉니다.
   - 즉, `.env.example` 의 내용을 그대로 가진 `.env` 파일을 만드는 거예요.
   - 이름은 점으로 시작하는 **`.env`** 가 정확합니다. (`.env.txt` 아님!)
3. `.env` 파일을 **메모장**으로 엽니다. (우클릭 → 연결 프로그램 → 메모장)
4. 안에 이런 줄이 있을 거예요:

   ```
   ANTHROPIC_API_KEY=sk-ant-...
   ```

5. `sk-ant-...` 부분을 지우고, **1단계에서 복사한 내 진짜 키**를 붙여넣습니다. `=` 다음에 띄어쓰기 없이 바로 붙입니다.

   예시(가짜 키):
   ```
   ANTHROPIC_API_KEY=sk-ant-여기에내키전체를붙여넣기
   ```

6. **저장**(Ctrl + S)하고 메모장을 닫습니다.

> 그 아래에 있는 `OPENCLAW_MODEL`, `OPENCLAW_EFFORT`, `OPENCLAW_MAX_TOKENS`, `PORT` 같은 줄은 **그대로 두세요**. 안 건드려도 잘 돌아갑니다.

> ✅ **성공 신호**: `.env` 파일을 다시 열었을 때 `ANTHROPIC_API_KEY=` 뒤에 내 키가 붙어 있어요.
>
> ❌ **막히면**: 파일 이름이 `.env.example` 그대로거나 `.env.txt` 로 되어 있으면 인식이 안 돼요. 정확히 **`.env`** 여야 합니다.

## 3. 우리 가게 정보를 `business.json`에 적기

`business.json`은 **AI가 손님에게 답할 때 보는 우리 가게 안내문**이에요. 여기 적힌 내용 안에서만 답합니다. (없는 내용은 지어내지 않아요.)

1. 폴더에서 **`business.example.json`** 파일을 찾습니다.
2. 복사한 뒤 이름을 **`business.json`** 으로 바꿉니다. (예시 안내문을 복사해서 우리 가게용으로 만드는 거예요.)
3. `business.json` 을 **메모장**으로 엽니다.
4. 안에는 예시로 미용실 정보가 들어 있어요. 이걸 **우리 가게 내용으로 바꿔** 적으면 됩니다.

각 칸의 뜻은 이렇습니다(예시는 미용실):

| 칸 이름 | 뜻 | 예시 |
|---|---|---|
| `shopName` | 가게 이름 | `"행복미용실"` |
| `industry` | 업종 | `"미용실"` |
| `hours` | 영업시간·휴무 | `"화~일 10:00 - 20:00 (매주 월요일 휴무)"` |
| `address` | 주소 | `"서울시 마포구 행복로 12, 2층"` |
| `phone` | 전화번호 | `"02-123-4567"` |
| `menu` | 메뉴/가격 목록 | 아래 설명 참고 |
| `faq` | 자주 묻는 질문과 답 | 아래 설명 참고 |
| `notes` | AI에게 알려줄 추가 안내 | `"실제 예약 확정은 전화로 도와드립니다."` |

`menu`(메뉴)는 이렇게 생겼어요. `name`(이름)과 `price`(가격)을 한 줄씩 적습니다:

```json
"menu": [
  { "name": "커트", "price": "15,000원" },
  { "name": "펌", "price": "80,000원 ~" }
]
```

`faq`(자주 묻는 질문)는 `q`(질문)와 `a`(답)을 적습니다:

```json
"faq": [
  { "q": "예약 꼭 해야 하나요?", "a": "워크인도 받지만 예약을 추천드려요." },
  { "q": "주차 되나요?", "a": "건물 뒤편에 2시간 무료 주차가 가능합니다." }
]
```

### 메모장으로 고칠 때 꼭 지켜야 할 규칙 ✍️

이 파일은 컴퓨터가 읽는 형식(JSON)이라 **기호를 정확히** 지켜야 해요. 글자만 바꾸고 기호는 건드리지 마세요.

- 글자는 항상 **큰따옴표 `" "`** 로 감쌉니다. (작은따옴표 `'` ❌)
- 각 항목 끝에는 **쉼표 `,`** 가 있어야 해요. 단, **마지막 항목 뒤에는 쉼표를 빼야** 합니다.
- 여는 괄호 `{` `[` 와 닫는 괄호 `}` `]` 의 **짝**이 맞아야 해요. (개수를 늘리거나 줄이지 마세요.)
- 따옴표 안의 내용(가게 이름, 가격 등)만 바꾸면 안전합니다.

> 💡 메뉴나 FAQ를 **줄여도** 됩니다. 한 줄을 통째로 지울 때는 그 줄 끝의 쉼표까지 같이 신경 쓰세요. 자신 없으면 글자만 바꾸고 줄 개수는 그대로 두는 게 가장 안전해요.

5. 다 고쳤으면 **저장**(Ctrl + S)합니다.

> ✅ **성공 신호**: 가게 이름, 시간, 메뉴, 전화번호가 우리 가게 것으로 바뀌어 있어요.
>
> ❌ **막히면**: 기호 실수가 있으면 다음 단계에서 오류가 나요. 6번 문제 해결 칸을 보세요.

## 4. 설치하고 실행해서 손님처럼 대화해 보기

이제 터미널(검은 창)에서 두 줄만 입력하면 됩니다.

### 4-1. 필요한 부품 설치 (처음 한 번만)

터미널에 아래를 입력하고 Enter:

```
npm install
```

- 이건 챗봇에 필요한 **부품들을 자동으로 내려받는** 명령이에요. 인터넷이 필요합니다.
- 글자가 주르륵 올라가고 1~3분 정도 걸려요. 기다리세요.

> ✅ **성공 신호**: 다시 입력할 수 있는 `>` 줄로 돌아오고, 빨간 `error` 글자가 없어요.
>
> ❌ **막히면**: `npm` 을(를) 모른다는 오류(`'npm'은 인식할 수 없는...`)가 나면 Node.js가 제대로 설치 안 된 거예요. Node.js를 다시 설치한 뒤 터미널을 껐다 켜고 다시 시도하세요.

### 4-2. 챗봇과 대화하기

터미널에 아래를 입력하고 Enter:

```
npm run chat
```

- 이건 **터미널 안에서 챗봇을 손님처럼 테스트**하는 명령이에요.
- 잠시 후 입력 안내가 나오면, **손님이 물어볼 법한 질문**을 한글로 적고 Enter를 눌러 보세요.
  - 예: `영업시간 어떻게 되나요?`
  - 예: `커트 얼마예요?`
  - 예: `주차 되나요?`
- AI가 우리 `business.json` 내용을 바탕으로 답합니다.
- 끝낼 때는 `Ctrl + C` 를 누르거나 창을 닫으면 됩니다.

> ✅ **성공 신호**: 내가 적은 질문에 우리 가게 정보(시간·가격 등)로 또박또박 답해요. 🎉 여기까지 되면 챗봇은 완성된 거예요!
>
> ❌ **막히면**: 아래 6번 문제 해결 칸을 보세요.

## 5. (선택) 살짝 점검만 해보기

API 키 없이 프로그램이 잘 켜지는지 빠르게 확인하고 싶다면:

```
npm run smoke
```

- 이건 **AI를 부르지 않고** 프로그램이 정상인지 스스로 점검하는 명령이에요. 돈이 들지 않아요.
- 결과 줄이 나오면 정상입니다. (대화는 못 해요. 대화는 `npm run chat` 으로.)

## 6. 😵 막혔을 때 — 자주 나는 오류 모음

> 🔧 **오류: API 키가 설정되지 않았다 / `ANTHROPIC_API_KEY` 관련 메시지**
> - 원인: 키를 안 넣었거나, 파일 이름이 `.env` 가 아니에요.
> - 해결:
>   1. 챗봇 폴더에 **`.env`** 파일이 있는지 확인 (`.env.txt`, `.env.example` 아님).
>   2. 그 안 `ANTHROPIC_API_KEY=` 뒤에 내 키(`sk-ant-...`)가 **띄어쓰기 없이** 붙어 있는지 확인.
>   3. 저장(Ctrl + S) 후 터미널을 껐다 켜고 다시 `npm run chat`.

> 🔧 **오류: 결제/크레딧 관련 (billing, credit, payment 등 영어 메시지)**
> - 원인: Claude 사이트에 카드/결제가 등록되지 않았어요.
> - 해결: **https://platform.claude.com** → **Billing** 에서 카드 등록 또는 소액 충전 후 다시 시도.

> 🔧 **오류: business.json 관련 / `JSON` / `Unexpected token` 같은 메시지**
> - 원인: `business.json` 의 기호(따옴표·쉼표·괄호)가 어긋났어요.
> - 해결:
>   1. 큰따옴표 `" "` 를 썼는지 (작은따옴표 ❌).
>   2. 각 줄 끝 쉼표가 맞는지, **마지막 항목 뒤에는 쉼표가 없는지**.
>   3. `{ } [ ]` 괄호 짝이 맞는지.
>   4. 자신 없으면 `business.example.json` 을 **다시 복사**해서 `business.json` 으로 만들고, **글자만** 조심해서 바꾸세요.

> 🔧 **오류: `'npm'은 인식할 수 없는 명령...`**
> - 원인: Node.js가 설치 안 됐거나 인식이 안 돼요.
> - 해결: Node.js를 (다시) 설치하고, **터미널을 껐다 켠 뒤** 다시 시도.

> 🔧 **그래도 안 될 때**
> - 터미널의 **빨간 글자 줄을 그대로 캡처**해 두세요. 도와줄 사람에게 보여주면 원인을 금방 찾을 수 있어요. (단, `.env` 의 API 키는 가리고 보여주세요!)
